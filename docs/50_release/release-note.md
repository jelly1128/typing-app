# リリースノート

## v1.0(MVP初回リリース、2026-09-12)

日本語タイピング練習アプリのMVPを公開。

### 実現した機能(FR一覧)

| FR-ID | 内容 |
|---|---|
| FR-01 | お題文を表示する(難易度別お題セットからローテーション出題) |
| FR-02 | ローマ字入力を判定する(清音の異表記/拗音/撥音「ん」/促音「っ」/長音を許容) |
| FR-03 | 入力状態をリアルタイムに表示する(確定文字/次に打つ文字/ミス位置) |
| FR-04 | ミスを記録する(期待キー・実際のキー・直前のかな・文字種を記録) |
| FR-05 | セッションの終了条件を判定する(お題N文 または 制限時間) |
| FR-06 | セッション結果を算出する(Net KPM・Raw KPM・正確率・Consistency) |
| FR-07 | セッション結果を保存する |
| FR-08 | 練習履歴を一覧表示する |
| FR-09 | 自己ベストを表示する(難易度ごと) |
| FR-10 | ミスの傾向を分析する(かな別/誤りパターン別/直前のかな別/文字種別) |
| FR-11 | 改善アドバイスを表示する |
| FR-12 | 利用者を識別する(名前入力のみ、認証なし) |
| FR-13 | お題セット(難易度)を選択する |

詳細は[requirements.md](../10_requirements/requirements.md)を参照。

### 既知の制約・受入リスク

- **認証機能なし**: 利用者識別は名前入力のみ。同じ名前を入力すれば同一人物の記録として扱われる([ADR-001](../00_project/decisions/001-auth-out-of-scope.md))
- **userId推測による他人データ閲覧**: `userId`を知っていれば他人の履歴・自己ベスト・ミス分析を閲覧できる。学習目的の個人開発であり保存データに機微情報を含まないため、受入リスクとして扱っている([ADR-003](../00_project/decisions/003-userid-enumeration-accepted-risk.md))
- **バックアップ非対応**: Render無料プランのDBはバックアップ機能が無く、作成から30日+猶予14日で自動失効する(`nonfunctional-design.md` NFR-08参照)。長期運用や重要な記録の保持は想定していない
- **お題文の追加・編集UIなし**: お題文は開発者によるシードデータ投入のみで、利用者が追加・編集することはできない(FR-13備考)
- **既知の軽微な不具合**: 履歴画面で自己ベスト取得と履歴取得が同時にuserId失効(404)を検知すると、ログアウト処理が2回走ることがある(実害なし、対応見送り。詳細は[bug-list.md](../40_test/bug-list.md) BUG-002)

### 動作環境

- Render無料枠でホスティングしているため、しばらくアクセスが無いとサーバーがスリープし、初回アクセス時の起動に時間がかかることがある
