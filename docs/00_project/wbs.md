# WBS・見積もり

## 使い方

- **工程レベル**の見積もりは計画時に置いた粗い値。工程に着手する直前に**タスクレベルへ分解**する
- タスクは **2〜4時間で終わる粒度**まで割る(これがボトムアップ見積もりの訓練)
- 各タスクには**完了条件を1行**書く。「◯◯ができた状態」の形にする
- 見積もりは `/ty-plan` で **Kazuki が先に出す**。実績は `estimate-actual.md` に追記する
