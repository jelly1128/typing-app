# 先送り事項台帳

レビュー指摘(B/C)・未決事項・「今は対応せず後で検討する」と決めた項目を一元管理する台帳。**新しく先送りする項目は必ずここに登録する。**

## この台帳を作った理由(2026-09-12、P8)

CL-027/CL-028/CL-030/CL-031と、担当タスクIDを割り当てないまま先送りした事項が次々に自然消滅し、後工程で「未実装/未転記だった」と発覚する再発が続いた(直近ではP3ゲート③レビューのB/C計11件がwbs.mdのどのフェーズにも転記されず、P7-04着手直前まで気づかれなかった)。原因は先送り事項の置き場が`wbs.md`の表外の文章や`progress.md`の記述に散在し、**存在を確認する専用の手順が無かった**こと。この台帳と、`/ty-plan`で毎回open項目を読み上げる手順(`.claude/commands/ty-plan.md`参照)でこれを解消する。

## 記録ルール

- 新規項目は末尾に追記する(既存行は書き換えない。`status`列だけ更新して対応状況を反映する)
- **`対象工程`が未定の項目は「未定」と明記し、決まり次第この行を更新する。** 「担当タスクIDが無いまま先送りされた事項は自然消滅する」という再発パターンを防ぐため、未定のまま放置しない
- `status`: `open`(未対応) / `resolved`(対応済み、対応内容と日付を記載) / `rejected`(対応しないと決定、理由を記載)
- レビュー指摘票(`docs/90_review/*.md`)由来の項目は、指摘IDをそのまま`発生源`に書く
