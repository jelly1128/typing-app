# プロジェクト憲章

## 1. 背景・目的

日本語タイピングアプリを開発する。ただしアプリの完成は目的の1つに過ぎず、本プロジェクトは3つの目的を同時に達成する。

1. **SI 企業風のウォーターフォール工程を一通り体験する** — 成果物とレビューゲートを伴う形で全工程を回す
2. **Claude Code の機能(commands / agents / skills / rules / hooks)を実地で整備する** — 工程の進行と機能習得を同じ作業で両立させる
3. **build → deploy → document のフルループを一度通し切る** — 過去に未達だった目標

副次的な目的として、**WBS とボトムアップ見積もりの訓練**を全セッションで強制的に回す。

## 2. 完了条件

> 公開 URL で他人がタイピングでき、記録が DB に残り、`docs/` に要件〜テストの全成果物が揃い、工程別の見積り/実績ズレ率が数値で出ている状態。

## 3. スコープ

### スコープ内(MVP・P1 で正式確定)
- 日本語のお題文に対するローマ字入力判定(複数表記許容)
- タイピングセッションの実行とリアルタイム表示
- 結果算出(KPM / 正確率 / 所要時間)と DB 保存
- 履歴一覧・自己ベスト表示
- お題セット管理(DB 保持、難易度別)
- ユーザー識別は**名前入力のみ**(認証なし)

### スコープ外(拡張課題)
認証(Spring Security + JWT) / ランキング / 苦手キー分析 / お題投稿機能 / WebSocket 対戦 / 英語モード / かな入力

**スコープ外にした理由:** 完走を最優先する。認証だけで +2〜3 セッションかかり、デプロイ到達が遠のく。

## 4. 体制

| 役割 | 担当 |
|---|---|
| PM / 設計 / 実装 | Kazuki |
| レビュアー | Claude(独立コンテキストのサブエージェント) |
| 壁打ち相手 | Claude(対話セッション) |

**1人開発のレビュー問題:** 同じ会話にいる Claude は自分が書いた設計を肯定しやすいため、レビューは**成果物ファイルだけを渡した独立コンテキストのエージェント**が行う。

## 5. スケジュール

| 項目 | 値 |
|---|---|
| 開始日 | 2026-08-22 |
| 想定セッション数 | 22〜30 |
| 1セッション | 2〜3時間(休日中心) |
| 想定ペース | 週 1〜2 セッション |
| 想定完了時期 | 2026年11月末 〜 12月末 |

**縮小の判断ポイント:** P5(実装)が 8 セッションを超えたら履歴画面を切って P6 へ進む。デプロイ到達を最優先する。

## 6. 技術スタック(P2 で正式確定)

| 層 | 選定 | 備考 |
|---|---|---|
| フロント | Vue 3 + Vite + TypeScript + Pinia | |
| バック | Java 25 + Spring Boot 4.x + Maven | Spring Boot 4.0 が Java 25 を first-class support |
| DB | PostgreSQL 16 + Flyway | ローカルは Docker コンテナ |
| デプロイ | Render(Web Service + Managed Postgres) | Fly.io が次点。AWS は +3 セッションのため P9 送り |

## 7. 前提・制約

- 学習目的の個人開発。品質より**工程を回し切ること**と**学びの深さ**を優先する
- Kazuki は初心者寄り。実装の理由や選択肢の背景を丁寧に説明する
- 見積もりは**必ず Kazuki が先に出す**(Claude の値に引っ張られると訓練にならない)
- 未導入ツール: Docker / PostgreSQL / GitHub CLI(P0 で導入)

## 8. リスクと対策

| リスク | 対策 |
|---|---|
| 最後のデプロイでインフラにハマり未完で終わる | P2.5 で Walking Skeleton を先に本番へ出す |
| 設計とコードが乖離する | 実装中の差異は先に設計書を直し、`change-log.md` に記録する |
| 実装が膨らんで完走できない | P5 が 8 セッション超で機能を切る判断ポイントを設定済み |
| 見積もりが甘く計画が崩れる | 毎セッション実績を記録し、直近3回のズレ率から補正係数を出す |
| ロジック層に framework 依存が混入し多言語移植できなくなる | Maven マルチモジュールでビルドレベルで強制 + P5 で hook による検査を追加 |
