# 用語集

use-cases.md / requirements.md で使う、ローマ字入力判定まわりの用語を定義する。特に**本プロジェクト内での限定的な使い方**をしている語は、その旨を明記する。

## 1. かな・音の単位

| 用語 | 定義 |
|---|---|
| 拍(はく)/ かな1拍 | 日本語における発音の最小単位であり、ミス分析(FR-04/FR-10)の集計単位。原則ひらがな1文字だが、拗音(「しゃ」等)は2文字で1拍として扱う。ローマ字では通常1〜4キーの入力に対応する(例: 「し」=2キー"si"、「しゃ」=3キー"sya")。**入力判定(FR-02/FR-03)の単位はキー(下記「キー入力(判定単位)」参照)であり、拍単位ではない** |
| 清音 | **本プロジェクトでの用法**: 拗音・撥音「ん」・促音「っ」・長音のいずれにも該当しない基本的なかな。濁音(が・ざ・だ・ば行)・半濁音(ぱ行)もここに含める(ローマ字表記の分岐が少なく、他の特殊カテゴリほど複数表記の曖昧さがないため) |
| 拗音 | 小さい「ゃ・ゅ・ょ」を伴う音。例: しゃ、きょ、ぴゅ |
| 撥音「ん」 | はねる音。ローマ字では "n" 単独または "nn" のいずれかで表記される(FR-02 参照) |
| 促音「っ」 | つまる音。ローマ字では次に続く子音を重ねて表記する(例: がっこう→gakkou の "kk") |
| 長音「ー」 | 音を伸ばす表記。直前の母音表記に応じて延長する |
| 文字種(文字種別) | 上記5分類(清音/拗音/撥音「ん」/促音「っ」/長音)の総称。FR-04 のミス記録・FR-10 のミス分析で使うタグ |

## 2. ローマ字入力

| 用語 | 定義 |
|---|---|
| ローマ字表記ゆれ | 同じかな1拍に対して複数の正しいローマ字表記が存在すること。ヘボン式・訓令式など、由来の異なる複数の方式が混在して使われることに起因する |
| ヘボン式 | ローマ字表記法の一つ。英語話者に発音が伝わりやすい表記(例: し→shi、つ→tsu) |
| 訓令式 | ローマ字表記法の一つ。かなの行と段の規則性を重視した表記(例: し→si、つ→tu) |
| IME(Input Method Editor) | 日本語入力のための変換ソフトウェア。通常はローマ字入力→かな→漢字変換を担う。**本アプリは IME を介さず、ローマ字キー入力そのものを直接判定する**(FR-02 の前提) |
| キー入力(判定単位) | FR-02/FR-03 における正誤判定の最小単位。ローマ字のアルファベット1文字ずつを指す(拍単位ではない) |

## 3. 成績・分析指標

| 用語 | 定義 |
|---|---|
| KPM(Keystrokes Per Minute) | 1分あたりのキー入力数。本プロジェクトでは Net KPM と Raw KPM の2種類を使う |
| Net KPM | 正しく確定したキー入力数のみを基準に算出した KPM(ミス分は含まない) |
| Raw KPM | ミスを含む総キー入力数を基準に算出した KPM |
| 正確率 | 正しく確定したキー入力数 ÷ 総キー入力数(ミス含む)。同じ拍で複数回ミスした場合はその回数を総キー入力数に含める |
| Consistency | 1キー入力ごとの入力間隔(ミリ秒)のばらつき。値が小さいほど安定して打てていることを示す |
| 誤りパターン | ミス分析(FR-10)における、「期待していたキー → 実際に入力されたキー」の組み合わせ |

## 4. お題・セッション

| 用語 | 定義 |
|---|---|
| お題 | 1回のタイピング対象となる日本語の文 |
| お題セット | 難易度別にグループ化されたお題の集合 |
| セッション | 利用者が開始してから終了条件(お題 N 文 完了 / 制限時間経過)を満たすまでの一連のタイピング練習の単位 |
